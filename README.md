# 📦 План поставок v2.0

**Умное планирование поставок с автоматическим формированием**

Система для автоматического планирования поставок товаров на основе данных из Google Sheets с учетом остатков на складах, средних продаж и времени доставки по различным складам.

## 🚀 Возможности

### 📊 План поставок (Supply Planning)
- **Автоматическое формирование поставок** с настраиваемыми параметрами
- **Приоритизация по дням запаса** (7, 14, 21, 30 дней)
- **Распределение по складам** с учетом времени доставки:
  - Рязань (1 день) - экстренные поставки
  - Котовск (3 дня) - приоритетный склад
  - Самара (4 дня) - стандартная доставка
  - Краснодар + Невинномысск (7 дней) - совместная доставка
  - Екатеринбург (7 дней) - стандартная доставка
- **Лимиты поставок** (по умолчанию 5500 штук)
- **Детализированные отчеты** по каждой поставке
- **Экспорт данных** в различных форматах

### 📦 План упаковки (Packaging Planning)
- **Подготовка товаров к поставке** на основе остатков
- **Фильтрация по приоритету** (7/14/30 дней)
- **Отслеживание КИЗ** (готовые/требующие нанесения)
- **Статистика упаковки** с процентом готовности
- **Список задач** для упаковки товаров

### 🔗 Интеграция с Google Sheets
- **Автоматическая загрузка данных** из двух таблиц:
  - Аналитика по товарам (остатки, продажи, коэффициенты)
  - Упакованные товары (готовые коробки, КИЗ статусы)
- **Реального времени обновления**
- **Безопасное подключение** через Service Account
- **Демо-режим** с тестовыми данными при отсутствии API ключей

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd supply-planning-system
```

### 2. Установка зависимостей
```bash
# Установка серверных и клиентских зависимостей
npm run install-all

# Или по отдельности:
npm install                 # Серверные зависимости
cd client && npm install    # Клиентские зависимости
```

### 3. Настройка окружения
```bash
# Скопируйте пример конфигурации
cp .env.example .env

# Отредактируйте .env файл с вашими настройками:
# - Google Sheets API credentials
# - ID таблиц Google Sheets  
# - Другие параметры
```

### 4. Настройка Google Sheets API

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите Google Sheets API
3. Создайте Service Account и скачайте JSON ключ
4. Добавьте email сервисного аккаунта в настройки доступа к вашим таблицам
5. Скопируйте данные из JSON в .env файл

### 5. Запуск в режиме разработки
```bash
# Запуск сервера и клиента одновременно
npm run dev

# Или по отдельности:
npm run server    # Запуск только сервера (порт 5000)
npm run client    # Запуск только клиента (порт 3000)
```

### 6. Запуск с PM2 (Production)
```bash
# Создание директории для логов
mkdir -p logs

# Установка PM2 глобально
npm install -g pm2

# Запуск с PM2
pm2 start ecosystem.config.js

# Просмотр статуса
pm2 status

# Просмотр логов
pm2 logs --nostream

# Остановка
pm2 stop all
```

## 🔧 Конфигурация

### Google Sheets структура

#### Таблица аналитики (Лист "1ИП"):
- **Колонка B**: Штрих-код товара
- **Колонка C**: Артикул
- **Колонка D**: Остаток на складе ВБ
- **Колонка F**: Средние заказы за день (за 3 дня / 3)
- **Колонка G**: Заказы за вчера
- **Колонка I**: Готовые коробки на нашем складе
- **Колонка J**: Неготовые остатки на нашем складе
- **Колонка L**: На сколько дней хватит товара
- **Колонка Q**: Сколько нужно закупить (на 5 недель)
- **Колонка V**: Сколько нужно отвезти (на 3 недели)
- **Колонки Z-AE**: Коэффициенты на будущие недели

#### Таблица упаковки (Лист "Упакованный товар"):
- **Колонка E**: Артикул
- **Колонки M-AJ**: Индивидуальные коробки
- **Колонки AN-BD**: Микс коробки
- **Цветовая кодировка**: Зеленые ячейки = КИЗ нанесен

### Параметры системы

#### Склады и время доставки:
- **Рязань**: 1 день (экстренные поставки)
- **Котовск**: 3 дня (приоритетный, 40% объема)
- **Самара**: 4 дня (25% объема)
- **Краснодар + Невинномысск**: 7 дней (20% объема, совместная доставка)
- **Екатеринбург**: 7 дней (15% объема)

#### Ограничения доставки:
- **Группа 1**: Котовск + Краснодар/Невинномысск (один день)
- **Группа 2**: Самара + Екатеринбург (один день)  
- **Группа 3**: Рязань (отдельно, экстренно)

## 🌐 API Documentation

### Analytics Endpoints
- `GET /api/analytics/data` - Получить данные аналитики
- `GET /api/analytics/warehouse-distribution` - Распределение по складам
- `GET /api/analytics/summary` - Сводка аналитики
- `GET /api/analytics/critical-products` - Критичные товары

### Packaging Endpoints  
- `GET /api/packaging/packed-goods` - Упакованные товары
- `GET /api/packaging/preparation-list?priority=14` - Список для подготовки
- `GET /api/packaging/summary` - Статистика упаковки

### Supply Endpoints
- `POST /api/supply/generate-auto-supply` - Генерация автоматических поставок
- `GET /api/supply/formed-supplies` - Сформированные поставки
- `GET /api/supply/supply-details/:id` - Детали поставки
- `GET /api/supply/warehouse-capacities` - Мощности складов

## 📝 Использование

### 1. Автоматическое формирование поставок
1. Перейдите на вкладку "Авто поставки"
2. Настройте параметры:
   - Лимит на поставку (штук)
   - Приоритет дней (7/14/21/30)
   - Количество поставок в неделю
   - Приоритетный склад
3. Нажмите "Сформировать поставки автоматически"

### 2. Подготовка товаров
1. Перейдите на вкладку "Подготовка товаров"
2. Выберите фильтр по приоритету (7/14/30 дней)
3. Просмотрите список товаров требующих подготовки
4. Экспортируйте задания по приоритету или выполненные

### 3. Мониторинг и аналитика
- Отслеживайте статистику в реальном времени
- Просматривайте детали каждой поставки
- Экспортируйте отчеты для дальнейшего анализа
